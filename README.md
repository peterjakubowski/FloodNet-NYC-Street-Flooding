# FloodNet-NYC-Street-Flooding

An exploratory data analysis of NYC street flooding events as detected and measured by FloodNet sensors.

View the notebook [here](https://github.com/peterjakubowski/FloodNet-NYC-Street-Flooding/blob/main/notebooks/floodnet_nyc_street_flooding.ipynb).

The datasets used in this repository are free to download from the [NYC Open Data](https://www.nyc.gov/opendata) website.

More information on the FloodNet (New York University and The City University of New York) project can be found here: [https://www.floodnet.nyc](https://www.floodnet.nyc)
